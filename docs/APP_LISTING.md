# App Store Listing Plan

## App Name

**Countdown Timer Bar — Urgency & Sales**

Rules: Descriptive, keyword-rich, no superlatives ("best", "only", "#1").

## Tagline

"Real countdown timers with built-in analytics — see the clicks they drive."

## Short Description (≤80 chars)

"Countdown timer bar with built-in analytics. No fake timers. No guesswork."

## Key Benefit Bullets (appear in listing)

- **Set up in 2 minutes.** No coding required. Configure, install in your theme, and go live.
- **Honest urgency.** Your sale deadline is stored server-side so every visitor sees the same countdown — no resets on refresh.
- **See your ROI.** Built-in analytics show impressions, clicks, and click-through rate directly in the app.
- **Works on all themes.** Built on Shopify's Theme App Blocks — no code injected into your theme files.
- **Fully customizable.** Choose colors, position (top or bottom), message, and what happens when the timer ends.
